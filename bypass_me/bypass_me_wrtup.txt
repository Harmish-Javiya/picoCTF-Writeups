most import part here is function name decode_password, we will come to that later

here above the decpde_password we have "leaq   -0x110(%rbp), %rax" line which shows that whatever decode_password is stored in the buffer which will be at the space (rbp - 0x110)
and then in its second line we have "movq   %rax, %rdi" where the data stored in the %rax is stored to %rdi and this is happening because it is AT&T Syntax (we can see that with the help of % and $ sign) 

in AT&T syntax always the syntax are like " function source destination " so in leaq function the buffer is stored to rax and then rax to rdi, so we have this functionality now to access that buffer place we have to run decode_password function and we achieve that with following:

5) type command => b decode_password , adding breakpoint to decode_password

6) command => run, to run the function

7) command => finish, to stop the function after compeleting the decode_password function

8) as we ran the decode_function we have to access our most beautiful place which is buffer place by this command => expr (char *)($rbp - 0x110), this will print the password for our .bin file which is, you want? it is => SuperSecure

9) then close the lldb with command => exit
